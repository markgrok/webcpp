= webcpp 0.1.0

In preparation: no tag names this version yet, and its libraries' entries
are their changelogs' "Unreleased" sections.

[#webcpp-0-1-0-new-libraries]
== New Libraries

* link:{library-pages}config/{library-page}[config]: webcpp's configuration,
which every library includes first: the target, exceptions and the version,
from R.
* link:{library-pages}pratt/{library-page}[pratt]: a header-only
Pratt-parsing engine for {cpp}20, with a decimal calculator built on it,
from R.
* link:{library-pages}trystero/{library-page}[trystero]: a port of
Trystero 0.26.0, serverless WebRTC rooms wire-compatible with the original,
for {cpp}20, from R.
* link:{library-pages}wasi/{library-page}[wasi]: a header-only HTTP handler
for {cpp}20 programs built as WebAssembly components, covering WASI 0.2 and
WASI 0.3, from R.
* link:{library-pages}xactor/{library-page}[xactor]: a header-only,
deterministic actor system for {cpp}20, from R.
* link:{library-pages}xstate/{library-page}[xstate]: a header-only port of
XState's state machines and actors for {cpp}20, from R.

[#webcpp-0-1-0-tools-and-build]
== Tools and build

* *Breaking change:* changed wasip2 programs to build with exceptions, as
wasip3 does; whether a program uses them is its developer's choice.
* Added emscripten as a tested target (Emscripten 6.0.11 under Node):
tests, link-only programs and driven tests, in CI and in own lanes.
* Added the lint rule `bare-throw`: a library header raises only through
`boost::throw_exception`.
* Changed the lint to analyse every aggregate, test and example without
exceptions too, so a library keeps compiling without them.
* Changed CI to run one own-lane job per library, lane and target,
installing Node only where needed; `b2 declared-lanes` prints each lane's
kind.
* Fixed an own lane that served nothing or missed a target passing
silently; it now fails by name.
* Fixed `serve.py` leaving wasmtime running when it is killed.
* Changed the lint's compilation database to include every program an own
lane builds, served programs included.
* Fixed the Node package installer leaving a stray link or a traceback
when an install is killed or refused.
* Added the names `target`, `has`, `no`, `lib`, `version` and `test`, alone
or before `_`, to those no library may take.
* Added the lint rule refusing an unescaped `+__X__+` in a Doc Comment's
code span.
* Added each version's release notes to the index page, newest first.
* Added the lint rule `changelog`: every changelog line keeps its form.
* Added `b2 check-release`, `b2 whats-new` and `b2 dist`, which check,
announce and package a release.
* Added `third_party/`, third-party code pinned as submodules: first the
JSON Schema Test Suite, which a test reads on every target through
`/webcpp/third_party//json-schema-test-suite`.
* Changed the lint to never read third-party code under `third_party/libs/`.
* Added `webcpp.generated`, which checks a library's generated files against
their Python generator, and `update-generated`, their only writer.
* Added `--files` to `tools/oracle/compare.py`, which compares two files
byte for byte.
* Added `/webcpp//boost_url`, Boost.URL built from Boost's sources for every
target, read from `BOOST_SOURCE` or `.local/boost-source`; another Boost
version's tree is refused.
* Changed the CI's Boost action to keep the sources of Boost's compiled
libraries; `install.sh source <dir>` fills a local tree.
* Changed the lint to never analyse a source outside the tree, such as
Boost's.
* Added `/webcpp//boost_charconv`, Boost.Charconv built from Boost's sources
for every target.
* Added `/webcpp//boost_locale`, Boost.Locale without ICU built from Boost's
sources for every target; a program that uses it needs exceptions.
* Fixed a lane's alias and a library's generated files running the
configuration check of Boost, which neither needs.
* Added `webcpp.data`, which gives a test a directory of the host's at the
same path on every target, through wasmtime's `--dir` on WASI.
