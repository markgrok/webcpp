= webcpp
:idprefix:
:sectanchors:

webcpp is a collection of header-only {cpp}20 libraries that bring to {cpp}
the libraries other languages use for the web. Each is built and tested with
b2, natively and for WebAssembly, and documented on a page of its own, with
its API reference.
